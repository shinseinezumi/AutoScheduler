仮想環境を自分で作成しないといけません。
以下の手順に従って作成してください。

１．仮想環境を作成するために、カレントディレクトリを移動する
実行するコマンド: cd api

２．仮想環境を作成する
python -m venv venv
備考：右下に「ディレクトリを移動しますか？」みたいなメッセージが出ることがありますが、無視してください。

３．仮想環境に入る
venv/scripts/activate

４．必要な機能をインストールする
pip install -r requirements.txt


＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝
AI機能について

AI機能はOllamaという外部のソフトを使っています。
AI機能を使用するにはこれをインストールする必要があります。
公式サイトからインストールして、コマンドで以下を実行してください。
ollama run phi3:mini
自動的に必要なものがインストールされて、対話が開始されます。
/byeと入力、もしくはCtrl+dで会話を終了してください。
